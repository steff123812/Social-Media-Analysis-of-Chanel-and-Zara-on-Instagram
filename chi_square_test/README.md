## Chi-Square Robustness Check (RQ1)

This folder contains a supplementary robustness check for RQ1 using chi-square tests.

Tests run:
1) Brand × Content Type (p = 4.09e-11, Cramér’s V = 0.489)
2) Brand × Influencer Type (p = 1.11e-07, Cramér’s V = 0.365)

Files:
- chi_square.py: script that runs the chi-square tests
- zara_posts_raw.xlsx: input dataset (Zara and Chanel in separate sheets)
